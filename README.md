## Ultimate Freeplay Trainer
### About
- This is a Rocket League plugin that you can install on bakkesmod.com.
- Its goal is to provide unlimited customization to your freeplay keybinds.
- Originally, you can only use the pre-defined presets that either Rocket League or BakkesMod created.
### Capabilities:
- **Keybind Mapping**: Specify which shots are mapped to which button. Allows for 4 completely unique presets to choose from 16 unique shots!
- **Name**: Name the preset whatever you'd like to ensure you always know what it does!
- **Position**: Define the ball's initial position anywhere on the field.
   - UI shows when ball will spawn OOB.
- **Direction**: Define the ball's initial velocity
   - Can set a static velocity in a direction
   - Or choose from a defined location on the field for the ball to launch at : car/leading car, goal, backboard.
- ***NEW*-Spin**: Define any spin you'd like to put on the ball.
- **Mirroring**: Define when you want the ball to mirror: random, based on where your facing, based on where you are on the field.
- **Variance**: Define randomness in the balls initial position via a cube or sphere bounding box. And/Or define randomness in the ball's initial direction.
- **Indicators**: Toggleable 3D indicators allowing you to know what the shot will look like before you save it!
